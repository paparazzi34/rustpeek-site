# RustPeek — веб-версия, v2

Полностью переписанная оболочка сайта. Старые `index.html` / `rustpeek_app.html`
лежат в `legacy/` — как справочник по логике, в сборку они не попадают.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # сборка в dist/
npm run preview      # посмотреть собранное
```

Бэкенд не поднят или недоступен? Открой любую страницу с `?mock=1` —
интерфейс отрисуется на демо-данных и честно скажет об этом полосой сверху.

## Деплой на Cloudflare

Раньше репозиторий был чистой статикой и Pages просто раздавал файлы из корня.
Теперь проект собирается, поэтому **нужно один раз поменять настройки сборки**
в дашборде Cloudflare (Workers & Pages → проект → Settings → Build):

| Параметр | Было | Стало |
|---|---|---|
| Build command | пусто | `npm run build` |
| Build output directory | `/` (корень) | `dist` |
| Node version | по умолчанию | 20+ (в репозитории лежит `.nvmrc` с `22`) |

Если Cloudflare всё равно берёт старый Node, добавь в Settings → Environment
variables переменную `NODE_VERSION` со значением `22`.

Дальше всё как раньше: пуш в ветку → Pages сам собирает и выкатывает.
Привязку `STATS_KV` трогать не надо, она остаётся на своём месте.

### Что делает `public/_worker.js`

При сборке он копируется в `dist/_worker.js` и обрабатывает запросы:

1. `/api/stats` — отдаёт JSON из `STATS_KV` (ровно как раньше);
2. `/assets/*`, которого нет, — честный 404. Без этого Pages отдаёт на такой
   путь `index.html` с кодом 200, и браузер падает с невнятным
   «MIME type text/html» вместо понятного «файл не найден»;
3. прямой заход на `/servers/123` — отдаёт `index.html`, чтобы клиентский
   роутинг подхватил маршрут (на Pages это работает и само, но подстраховка
   нужна, если проект переедет на Workers Static Assets);
4. всё остальное — статика как есть.

### Проверить деплой локально, до пуша

```bash
npm run preview:cf     # собирает и поднимает настоящий рантайм Cloudflare
```

Проверено на нём же, вручную:

| Запрос | Ответ |
|---|---|
| `/` | 200, `text/html` |
| `/servers/101` | 200, `text/html` (SPA-фолбэк) |
| `/assets/<реальный бандл>.js` | 200, `application/javascript` |
| `/assets/nope.js` | 404 |
| `/api/stats` | 503 `kv_unavailable` — локально KV не привязан, в проде будет 200 |

## Структура

```
src/
  lib/          типы, форматтеры, слой API, моки
  components/   ui-примитивы, иконки, графики
  layout/       SiteLayout (главная) и AppShell (приложение)
  features/
    landing/    главная страница
    servers/    список серверов и карточка сервера
    players/    досье игрока
    watchlist/  вочлист
    rustplus/   лента Rust+
  styles/       дизайн-токены
```

Маршруты:

| Путь | Что это |
|---|---|
| `/` | главная (лендинг) |
| `/servers`, `/servers/:id` | список серверов и карточка |
| `/players`, `/watchlist`, `/rustplus` | остальные вкладки приложения |

Поиск с главной уходит в `/servers?q=…` — тот же параметр, что был раньше.

## API

Контракт снят один в один со старого фронта — бэкенд менять не нужно.
Все эндпоинты собраны в `src/lib/api.ts`, все формы ответов — в `src/lib/types.ts`.

```
GET /api/servers/search?filter&sort&calendar&limit&offset&q
GET /api/servers/:id
GET /api/servers/:id/history?period&cycle_offset
GET /api/servers/:id/wipes
GET /api/servers/:id/hourly_profile
GET /api/player/:steamid_or_url
```

Если бэкенд отдаст новое поле — достаточно дописать его в `types.ts` и
использовать в компоненте; слой запросов трогать не надо.

## Дизайн-система

Токены живут в `src/styles/theme.css`, в одном месте. Правила, которые
стоит держать при доработках:

- **Один акцент** — ржавый `#e2622b`. Он означает «внимание/действие»,
  а не «данные вообще».
- **Статусы**: зелёный `#2fa26e` (подтверждено, свежо), ржавый (скоро, горячо),
  серый (нет данных). Красный `#d6453e` — только ошибки и баны, и он **никогда**
  не стоит рядом с ржавым в одном списке: при дейтеранопии эта пара
  неразличима (ΔE 4.4, проверено). Пара ржавый/зелёный проверена и проходит:
  CVD ΔE 9.2, обычное зрение ΔE 26.0, контраст ≥3:1.
- **Цвет никогда не единственный носитель смысла** — рядом всегда текст.
- **Анимации только функциональные**: переходы состояний 120–160 мс и одна
  пульсирующая точка «данные живые». Никаких появлений по скроллу — на старом
  сайте из-за них половина главной не отрисовывалась, если JS спотыкался.
- **Числа в колонках** — `tabular-nums` (класс `.tnum`), крупные одиночные
  числа — обычными пропорциональными цифрами.

## Правило про данные

Ни один блок не имеет права выдумывать. Если API молчит:

- счётчики на главной остаются на последних известных числах (они помечены
  в коде как фолбэки), а не показывают нули;
- лента событий и врезка «вайпнулись за сутки» просто не рисуются —
  выдуманные строки создавали бы впечатление, что мониторинг работает;
- карточка-пример на главной показывает слепок реального ответа за 25.07 и
  прямо подписывает, что это слепок;
- внутри приложения появляется полоса «демо-данные», если включены моки.
